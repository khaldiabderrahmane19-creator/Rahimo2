# رحيمو (Rahimo) — نسخة PWA جاهزة لـ GitHub Pages

## محتويات الحزمة
- `index.html`: التطبيق الأصلي مع ربط ملف manifest خارجي وأيقونة التطبيق.
- `manifest.json`: اسم التطبيق وإعدادات التثبيت على الهاتف.
- `sw.js`: Service Worker لتخزين واجهة التطبيق مؤقتًا ودعم فتحها دون اتصال بعد أول تحميل.
- `icons/`: أيقونتا 192×192 و512×512.

## طريقة النشر على GitHub Pages
1. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا (Repository)، مثل `rahimo-pwa`.
2. ارفع **جميع محتويات هذا المجلد** إلى جذر المستودع، وليس ملف ZIP وحده.
3. افتح `Settings` ثم `Pages`.
4. ضمن `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
6. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.
7. افتح الرابط عبر Chrome على الهاتف، ثم من القائمة اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

## ملاحظات مهمة
- يجب فتح التطبيق عبر HTTPS من GitHub Pages حتى يعمل التثبيت وService Worker بصورة صحيحة.
- بيانات هذا الإصدار تبقى في `localStorage` على الجهاز/المتصفح نفسه. **النشر على GitHub لا ينشئ قاعدة بيانات مشتركة ولا مزامنة بين الأجهزة**.
- الخريطة وخدمات الذكاء الاصطناعي التي تعتمد على الإنترنت قد لا تعمل دون اتصال. يلزم تحميل ملفات Leaflet الخارجية مرة واحدة على الأقل لاستخدامها دون اتصال، وقد تحتاج بعض الموارد الخارجية للإنترنت.
- إذا عدّلت الملفات بعد النشر، فقد تحتاج إلى تحديث الصفحة أو إغلاق التطبيق وفتحه لتحديث النسخة المخزنة.
- لا تضع مفاتيح API السرية داخل HTML المنشور علنًا؛ أي مفتاح في كود المتصفح يمكن للمستخدمين رؤيته.
